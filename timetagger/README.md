# TimeTagger

タグで分類するシンプルな時間記録（タイムトラッキング）アプリです。
作業内容に `#タグ` を書くだけで分類され、期間ごと・タグごとの集計を確認できます。

## 機能

- **タイマー**: 作業内容を入力して ▶ 開始 / ■ 停止。計測中も説明・タグを編集可能
- **タグ**: 説明文中の `#仕事` `#projectA` `#client/abc` などを自動抽出（大文字小文字は区別しません）
- **記録一覧**: 日ごとにグループ表示。▶ で同じ内容のタイマーを再開、✎ で編集・削除
- **手動追加**: 過去の作業を開始・終了時刻を指定して追加
- **レポート**: 日 / 週 / 月ごとの合計とタグ別の内訳バー
- **絞り込み**: タグをクリックするとそのタグの記録だけを表示（複数タグは AND 条件）
- **エクスポート**: 表示中の期間を CSV 出力、全データを JSON でバックアップ / 復元
- **ダークモード・スマホ表示対応**

データはブラウザの localStorage に保存されます（サーバー不要）。
ブラウザのデータを消すと記録も消えるため、定期的に「バックアップ」してください。

> 1 つの記録に複数タグがある場合、その時間は各タグにそれぞれ計上されます。
> そのためタグ別の合計の和は、期間の合計より大きくなることがあります。

## 使い方

```bash
cd timetagger
npm install
npm run dev      # http://localhost:5175
npm test         # ユニットテスト
npm run build    # dist/ に静的ファイルを出力
```

`npm run build` で生成される `dist/` は静的ファイルのみなので、GitHub Pages や Netlify などにそのまま置けます。

## 構成

```
src/
  App.jsx                 状態管理・画面全体
  lib/time.js             タグ抽出、期間計算、集計、CSV 変換
  lib/storage.js          localStorage 保存、ファイルダウンロード
  components/
    Timer.jsx             タイマー入力
    RecordList.jsx        日別の記録一覧
    RecordEditor.jsx      追加・編集モーダル
    Report.jsx            タグ別集計
    TagText.jsx           #タグのハイライト表示
```
